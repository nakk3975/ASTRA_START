# 설계 1.1 개정 기록

기준일 2026년 11월 16일. 현재 결과물은 계획과 정적 계산 자료이며 실제 게임·모델 제작은 아직 실행하지 않았다.

## 사용자 요구 반영

- 1~6인 협동 웹게임과 기존 생산·운반·자동화·로켓 건설 흐름 유지.
- 주요 모델을 Meshy AI 기반 실제 3D GLB로 제작하도록 변경.
- 고정 방향 정사영 카메라와 화면 중앙 정지 영역, 자동 따라가기 끄기, 수동 이동, 명시적 줌을 규정.
- 화면 흔들림·머리 흔들림·모션 블러·카메라 자유 회전·자동 줌을 사용하지 않음.

## 추가된 제작 계약

- 기본 자산 26종, 개별 영문 프롬프트 26개, 실제 제작 후 검수 행 26개.
- 작업자·가공기·하부 선체 3개를 먼저 검수하고 나머지 자산 제작.
- 실제 리깅과 독립된 여섯 작업자의 다섯 동작, 표준 축·피벗·크기, 로켓 모듈 접합.
- 카메라와 자산 JSON, 표시 객체와 서버 판정 분리, 버전·로딩·오류 처리 추가.
- 3D 관련 61개 인수 시험을 기존 99개에 추가하여 총 160개. 모두 NOT_RUN.

## 교차 검토에서 바로잡은 경계

- 설치 quarterTurns와 Three.js Y축 회전의 부호를 음수로 확정.
- 화면마다 dt를 단순 절단하지 않고 실제 경과 시간을 substep으로 소화하여 낮은 FPS 추적 속도 저하 방지.
- 비행 화물 192개에 손에 든 포드 6개를 더해 시각 포드 최대 198개로 계산.
- 높은 원료 더미 대신 매립한 낮은 트레이 사용. 24개 기존 수동 서비스 앵커와 시각 중심을 정확히 일치시킴.
- 60초 입장 ticket과 90초 UI 기다림을 구분하고 기본 자산 로딩 후 ticket 발급.
- 구 저장의 경제 hash chain을 유지하는 표시 adapter와 시각 버전 오류 코드를 명시.

## 보존과 검증

경제와 지도 JSON은 이전 버전과 바이트 단위 동일하다. 경제 21개 그룹, 제조 사건 18개 조건, 지도 446개 검사, 새 3D 설계 22개 그룹 검산을 통과했다. 실제 GLB 품질, GPU 성능, 사용자의 시각적 편안함과 완주시간은 구현 후 확인한다.
