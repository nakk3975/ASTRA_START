# 브라우저 조작 기록

2026-11-16, CUA Chrome. 이 브라우저는 WebGL 컨텍스트 생성이 실패하여 Canvas 2D 호환 렌더러를 사용했다. Three.js 렌더링 통과로 기록하지 않는다.

실행한 흐름:
1. 닉네임 입력 → 계획 인원 1 → 작업장 생성 → 복구 키 표시.
2. 방 접속, 준비 완료, 작업 시작. 저장 버전 갱신 확인.
3. WASD 유지 입력으로 금속 고철 채집 지점 이동, E 유지로 고철 4개 채집.
4. 작업대까지 키보드 이동. 범위 밖 요청은 안내와 함께 거부됨을 확인하고 근접 위치로 이동.
5. 주괴 제조법 적용, 고철 4개 투입, 제작 켜기. 실제 9초/회 제작으로 주괴 2개 출력 확인.
6. 제작 중지 후 출력 수거. 가방 ‘금속 주괴 2’와 빈 출력 확인.
7. 서버 재시작/페이지 새로고침 후 최근 작업장으로 같은 진행·가방 복원 확인.
8. 같은 게스트의 다른 탭에서 접속해 제어권을 교체함.

화면 시험은 qa.html의 실제 앱 iframe을 1366×768, 3840×2160, 800×360, 360×800 CSS 픽셀로 설정했다. 화면 축소 캡처는 원래 픽셀 크기를 표시한다. DOM client/scroll 크기가 각각 동일함을 확인했다. 데스크톱 HUD 및 로켓 패널, 모바일 가로 패널, 세로 회전 안내를 관찰했다. 세로 헤더가 화면 중앙에 배치되는 CSS 오류를 발견하여 bottom inset을 제거하고 수정 화면을 다시 확인했다.

이는 각 화면에서 게임을 처음부터 끝까지 수행한 시험이 아니다. 따라서 UX41~44의 전체 시나리오 PASS로 확장하지 않는다. 모바일은 실제 휴대전화 터치/성능 시험이 아니며, 화면 크기와 컨트롤 표시만 검증했다.
