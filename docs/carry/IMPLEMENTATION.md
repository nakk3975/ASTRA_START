# 채굴·성장·자동화 구현 보고서

기준: 2026-11-17 KST. 최신 사용자 지시가 첨부 원문의 바닥 줍기·단일 운반보다 우선합니다. 규칙 `mining-2.1.0`.

## 실제 적용

| 항목 | 이전 | 현재 |
|---|---|---|
| 원재료 | 바닥에 자동 생성 | 네 광맥, E로 0.6초 채굴 후 빈 운반 칸에 1개 생성 |
| 가공 | 짧은 단일 루프 | 11개 고정 기계, 재료→중간재→복합 부품 |
| 성장 | 고정 운반 | 팀 코인/XP, 운반량 1→2→3, 자동화 순차 해금 |
| 물류 | 직접 운반 중심 | 채굴기·직선/양방향 코너 벨트·크레인·트레이·설치기 |
| 캐릭터 | 기존 작업자 | 새 사람형 Meshy 모델, 안전모·주황 작업복·멜빵바지 |
| 화면 | 검수 화면 중심 | 실제 방 생성·참가·저장·게임 HUD, 모델 검수는 별도 경로 |

물건은 고유 ID를 갖습니다. 채굴부터 입력·가공·출력·설치까지 소유 상태가 명확하며 처리된 재료와 생산된 부품은 별도 ID입니다. 운반에서는 같은 ID를 전달합니다. 소유권 경합, 중복 비용, 재연결 중복 드롭을 차단합니다. 출력 3칸이 차면 생산과 보상을 대기합니다. 모든 플레이어가 나가면 시뮬레이션을 멈춥니다.

키 입력은 event.code 기준이며 입력창·모달·창 전환 시 이동을 중단합니다. 무거운 물건을 하나라도 들면 이동 속도는 80%입니다. 동료는 통과하고 벽·기계·플랫폼 절벽은 막힙니다. 경사로는 높이를 따라 이동합니다. WebGL 실패 시 3D 표시 없이 이동 성공을 가장하지 않도록 조작을 막고 실제 오류를 표시합니다.

## 보상과 업그레이드

모든 가공 완료 시 출력이 실제로 생성된 경우에만 팀 보상을 지급합니다. 채굴은 XP 1이며 코인은 없습니다. XP는 소비하지 않는 해금 조건입니다.

| 결과물 | 해당 공정 코인 | 해당 공정 XP |
|---|---:|---:|
| 주괴 | 2 | 2 |
| 전선 / 수지 | 1 | 2 |
| 철판 | 4 | 4 |
| 기어 | 3 | 4 |
| 회로 | 7 | 7 |
| 선체 패널 | 8 | 8 |
| 추진 탱크 | 9 | 9 |
| 엔진 부품 | 20 | 16 |
| 항법 부품 | 18 | 15 |

예: 고철→주괴는 2코인/채굴 포함 3XP, 이어서 철판까지 만들면 누적 6코인/7XP입니다. 설비 상자 제작 자체에는 보상이 없습니다. 하위 재료 공정 보상은 유지됩니다. 해금 비용은 자동화 장비를 무료로 지급하는 가격이 아니며 제작 재료가 별도로 필요합니다.

| 업그레이드 | 코인 | 필요 XP | 선행 |
|---|---:|---:|---|
| 운반 2개 | 12 | 10 | 없음 |
| 운반 3개 | 45 | 60 | 운반 2개 |
| 컨베이어 | 20 | 20 | 없음 |
| 자동 채굴 | 45 | 40 | 컨베이어 |
| 크레인 | 65 | 75 | 컨베이어 |
| 자동 설치 | 90 | 120 | 크레인 |
| 가공 속도 +25% | 50 | 70 | 없음 |

기계는 맞는 재료를 받으면 자동으로 가공합니다. 초반에는 재료/출력을 직접 옮기고, 후반에는 채굴기→벨트→기계→크레인→다음 기계→설치기로 연결합니다. 설치기는 2.7 범위 내 현재 단계의 맞는 소켓에 2초 동안 설치합니다. 틀린 부품은 기다리며 수동 회수할 수 있습니다. 설비 한도는 방당 120개입니다. 시설 철거·물류 분배기·자동 레시피 전환은 이번 구현에 없습니다. 경로는 직접 배치해야 합니다.

## 인원별 산출

방 생성 시 `ceil(기본량 × (1 + 0.35 × (기준 인원−1)))`로 품목별 수량 고정. 중간 입퇴장으로 줄어들지 않습니다. 아래는 로켓 필수 부품의 레시피 그래프 합계이며 설비 제작·추가 생산·운반 시간은 제외합니다. 공정 시간 합계는 병렬 가공을 반영하지 않은 기계 작업량이며 플레이 시간 예측이 아닙니다.

| 기준 인원 | 설치 부품 | 채굴 원재료 총개수 | 누적 코인 | 누적 XP | 기계 작업 합계(초) |
|---|---:|---:|---:|---:|---:|
| 1 | 16 | 34 | 264 | 302 | 324 |
| 2 | 24 | 51 | 396 | 453 | 486 |
| 4 | 39 | 84 | 654 | 748 | 800 |
| 6 | 47 | 101 | 786 | 899 | 962 |

1인 로켓 필수 생산만으로 모든 업그레이드(327코인)를 동시에 구매할 수는 없습니다. 우선순위를 선택하거나 추가 가공으로 자금을 벌 수 있습니다. 재료와 레시피별 상세는 `balance-analysis.json`입니다.

## 저장·배포 경계

기존 v1 테이블과 게임 규칙을 보존하고, 새 게임은 `carry_worlds_v2`에 저장합니다. carry-2.0.0 저장은 아이템·기계·소켓을 보존하면서 새 경제/운반 필드를 추가합니다. 이전 저장의 기계 배치는 자동 이동하지 않으므로 최신 배치는 새 작업장에 적용됩니다.

Node는 Colyseus WS+PostgreSQL, Sites는 HTTP 100ms 요청+서버 권위 D1 CAS입니다. hosted transport는 WS가 아닙니다. 요청이 늦으면 동기화도 지연될 수 있습니다. 생성된 drizzle migration을 사용하며 런타임 CREATE TABLE은 없습니다. Sites 공개 범위는 기존 소유자 전용으로 유지합니다. 게시 상태와 최신 소스는 `docs/RESUME.md`를 확인하세요.
