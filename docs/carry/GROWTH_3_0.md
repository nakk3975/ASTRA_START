# 공방 성장 3.0 — 구현과 밸런스

2026-11-17 KST · 규칙 workshop-3.0.0. 이전 mining-2.1.0 보고서는 당시 기록이며 현재 수치는 이 문서와 config.ts 기준입니다.

## 시작과 돈의 흐름

본편은 배치된 기계 없이 시작합니다. 팀 시작 자금은 `80 + 24 × (기준 인원 - 1)`입니다. 낡은 작업대 40코인을 사고 실제 상자를 운반·회전·배치합니다. 구매 자체는 설비 설치가 아닙니다. 벽·작업자·물건·기계·입출력 받침대를 침범하면 상자를 소비하지 않고 거부합니다. 빈 기계는 등급을 유지해 재포장할 수 있습니다.

낡은 작업대의 생산속도는 기준의 55%, 출력 2칸입니다. 주괴·전선·수지·철판·기어가 가능하고, 개량 등급에서 회로·선체·연료·설비 상자, 산업 등급에서 엔진·항법을 만듭니다. 전용 설비는 병렬 공정을 만들기 위한 투자입니다. 시작부터 설치되는 것은 개발 검증용 lab 모드뿐입니다.

가공할 때 XP만 지급합니다. 코인은 판매소 판매 또는 로켓 납품에서 물건마다 한 번 받습니다. 각 단계 완성 보너스도 한 번입니다. XP는 소모하지 않는 연구 자격 조건입니다. 원재료도 판매할 수 있어 돈을 잘못 써도 다시 모을 수 있습니다. 설비 상자는 재판매하지 않으며 무한 환불·보상 반복을 막습니다.

| 재료/부품 | 기본 판매·납품 코인 |
|---|---:|
| 고철·폐전선·폐플라스틱 / 동력석 | 1 / 2 |
| 주괴 / 전선·수지 | 5 / 4 |
| 철판 / 기어 / 회로 | 11 / 9 / 18 |
| 선체 패널 / 추진 탱크 | 35 / 32 |
| 엔진 / 항법 부품 | 85 / 75 |

## 독립 성장 경로

아래 비용은 1인 기준입니다. 공유 연구·기계 강화·광맥 비용은 `ceil(기본 비용 × (1 + .15 × (기준 인원 - 1)))`입니다. 실물 상자 구매 가격은 그대로이고 여러 명이 사용할 기계는 각각 사야 합니다. 중도 입퇴장으로 목표량·가격이 변하지 않습니다.

| 경로 | 효과 | 단계별 코인 | 단계별 요구 XP |
|---|---|---|---|
| 운반량 | 1→2→3→4→5→6→7→8개 | 18, 38, 70, 115, 180, 270, 390 | 8, 25, 55, 95, 155, 240, 350 |
| 이동속도 | +6%씩, 최대 +30% | 25, 55, 105, 180, 280 | 15, 45, 90, 160, 260 |
| 무거운 짐 운반 | 속도 손실 20%→16%→12%→8% | 40, 90, 170 | 35, 90, 180 |
| 채굴 도구 | 수동 채굴 0.8초→약 0.47초 | 28, 65, 130, 230 | 20, 55, 115, 210 |
| 레일 모터 | 한 칸 1.8→1.5→1.25→1.05→0.9초 | 50, 100, 180, 300 | 45, 100, 190, 320 |
| 가공 조율 | 모든 기계 +8%씩, 최대 +24% | 60, 130, 240 | 60, 130, 250 |
| 기계별 등급 | 생산속도 .55→.8→1.1→1.4, 출력 2→5칸 | 70, 150, 320 | 30, 75, 180 |
| 광맥별 품질 | 각각 1→5등급, 가치 최대 +60%, 채굴 시간 최대 ÷1.48 | 65, 150, 300, 520 | 55, 130, 260, 450 |

자동화는 레일(35코인/25XP) 다음에 채굴(70/65)과 크레인(100/100)으로 갈라지고 크레인 뒤 설치기(180/200)가 열립니다. 해금 뒤 상자 비용은 직선·코너 9, 트레이 5, 채굴기 100, 크레인 75, 설치기 150입니다. 가공 설비 가격은 작업대40·제련기100·부품제작기150·연료혼합기180·조립기240·설비제작대90입니다.

수량·속도·품질을 무제한으로 곱하지 않습니다. 광맥은 한 번에 1개를 유지하고 품질은 혼합 재료 중 최저 등급을 이어받습니다. 운반량 후반 가격은 크게 오르고, 이동속도는 상한이 있습니다. 모든 경로를 초반에 전부 올리는 구조가 아니라 손운반 집중, 전용 공정 병렬화, 자동 물류, 고품질 판매 중 투자를 나누도록 했습니다. 수치는 자동 시험 기준 초안이며 사람의 장시간 경제 플레이테스트는 별도로 필요합니다.

## 이동과 캐릭터

로컬 입력 예측은 권위 있는 게임 상태·재고를 바꾸지 않고 표시 좌표만 계산합니다. 서버와 같은 충돌 적분기를 쓰며 수신 위치 오차는 완만하게 보정합니다. 다른 사람의 좌표와 추적 카메라를 보간합니다. 900ms 동안 상태 수신이 없으면 추가 예측 이동을 멈춥니다. HTTP 경과시간을 0.25초로 잘라 버리던 처리를 1초 내 0.05초 하위 스텝으로 바꿨고 명령이 이동 입력을 초기화하던 WS 경로를 수정했습니다. 경사로 경계의 부동소수점 오차에 허용치를 적용했습니다. 걷기/정지 클립은 0.12초 전환합니다.

100~230ms 편도 지연, 60Hz CPU 계산 시험에서 프레임 이동량 변동계수는 기존 .6953에서 .0163으로 감소했습니다. 실제 GPU 프레임률을 측정한 값은 아닙니다. 충돌·방향 전환·정지·연결 중단도 시험했습니다.

4종 사람형 캐릭터는 각자 고릅니다. 능력은 동일하며 선택이 서버 저장과 재접속에 유지됩니다. 이번에 Meshy 3종을 추가 생성하고 18본·5클립·각2LOD를 연결했습니다. 신규45크레딧, 공급자 확인 잔액2399. 총29종/58활성GLB이며 생성 기록은 character-generation-v2.json입니다. 낡은 기계는 단순한 목제 작업대 형태로 렌더링하고 강화 후 실제 기계 모델로 바뀝니다.
