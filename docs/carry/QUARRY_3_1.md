# 채굴장과 이동 개선 — quarry-3.1.0

2026-11-17. 키를 놓은 뒤 한 번 더 이동하고 다시 멈칫하는 문제를 이동 프로토콜부터 수정했다. 단순 직진 보간 시험으로는 정지·재출발·왕복 통신의 순서 뒤섞임을 검증할 수 없었다.

## 이동

- 키다운·키업 때 즉시 입력 전송. HTTP 요청이 진행 중이어도 정지 입력을 추가 전송하며 동시 요청은 2개로 제한한다.
- 이동 방향을 서버에서 계속 적분하는 방식 대신, 번호와 지속시간을 가진 이동 구간을 처리한다. 서버가 확인한 번호 이후의 구간만 화면에서 재현한다. 중복 구간은 한 번만 적용하고 순서가 빠진 구간은 재전송을 기다린다.
- 서버 실제 시간 예산, 최대 구간 50ms, 최대 묶음 40개, 현재 접속 세대 검사로 클라이언트의 임의 속도 증가를 제한한다. 새 클라이언트에는 이전 입력으로 인한 서버의 추가 이동이 없다.
- 입력 제어 번호가 낮은 늦은 요청은 정지 방향을 덮어쓰지 않는다. 렌더 프레임·전송 타이머가 같은 예측 객체를 공유한다.
- 정지 후 작은 보정 잔량을 계속 움직이지 않도록 하고, 1.5m를 넘는 불일치는 복구한다. 카메라는 표시 위치를 직접 따라가며 정지 후 지연 이동하지 않는다. 손에 든 물건은 캐릭터의 표시 위치와 회전을 따른다.
- 고정 방향 정사영 카메라를 적용했다. 카메라 잠금과 거리 설정은 유지한다.
- 이전 클라이언트는 기존 프로토콜로 계속 접속 가능하지만, 새 이동 동작을 사용하려면 새로고침해야 한다.

## 자원과 외관

| 이전 표시 | 새 원재료 | 가공 결과 |
|---|---|---|
| 고철 | 철광석 | 철 주괴 → 철판·기어 |
| 폐전선 | 구리광석 | 구리선 |
| 폐플라스틱 | 규석 | 내열재 |
| 동력석 | 석탄 | 내열재와 함께 연료 카트리지 |

원재료 내부 ID는 기존 저장과 제작법 호환을 위해 유지했다. 석탄 채굴지는 석탄층으로 표시한다. 새 광물 모델 4개와 각각 LOD 2개를 교체했고, 운반하는 원재료도 광석·수정·석탄 덩어리 형태로 수정했다. 모델 출처와 실제 생성 작업은 `quarry-generation.json`에 기록되어 있다. 4회 생성·4회 텍스처, 60크레딧 사용, 마지막 확인 잔액 2339. 성공 모델의 추가 생성은 하지 않았다.

참고: [How They Built the Pyramids 공식 화면](https://store.steampowered.com/app/5458210/How_They_Built_the_Pyramids/). 참고 게임의 자산을 복사하지 않고 따뜻한 야외 손작업 분위기를 적용했다. 회색 격자·폐기물 수거함·금속 울타리를 흙길·목재 울타리·나무·바위 절벽·천막 판매소·돌 기초 발사대로 바꿨다. 작업장은 비어 있는 상태로 시작하며 설비는 구매 후 직접 설치한다. 기존 비용·가공 보상·운반 1→8·연구 조건은 유지했다.

정적 지형은 재질별 17개 메시로 합쳤다. 이것은 지형 메시 수이며 전체 게임 드로콜이나 FPS 측정값이 아니다. 겹치는 지면은 높이를 분리해 깜빡임을 방지했다. 화면 패널도 갈색·크림색 계열로 조정하고 배경 흐림 필터를 제거했다.

## 검증과 한계

- `npm run check`: 설계·92개 단위/통합 테스트·TypeScript·웹 빌드.
- 실제 PostgreSQL 및 Colyseus 6클라이언트: 물건 동시 획득, 이동, 정지, 늦은 중복 입력, 서버 반복 갱신 후 정지 위치 유지, 연결 종료 회수, SQL 재시작 복구.
- HTTP 동기화의 요청 70–190ms / 응답 60–180ms 지연 및 순서 변경 재현: 301프레임, 3번 출발·정지와 역방향. 정지 후 표시 이동 0, 마지막 서버와 위치 오차 0. `evidence/quarry-movement.json` 참조.
- 이전 workshop 저장의 경제·광맥·플레이어 보존 및 새 이동 프로토콜로 직접 채굴하는 흐름 검사.
- 원격 브라우저의 새 게임·시작 자금·채굴장 이름·자원 개발 메뉴 확인. 해당 브라우저는 WebGL2 컨텍스트 생성이 실패하므로 실시간 3D·FPS·실제 사용자 조작감은 검증하지 못했다.
- `evidence/quarry-offline-render.png`는 실제 게임 지형과 모델을 Blender CPU에서 렌더링한 외관 점검 자료다. 게임 화면 캡처나 GPU 성능 증거가 아니다.

```bash
node --import tsx scripts/export-quarry.ts
blender -b -t 4 -P scripts/render-quarry.py
```

기존 작업장도 새로고침하면 외관과 이동 변경이 적용된다. 자금·설비·물건·연구는 유지되며 새 저장 생성은 필수가 아니다.
