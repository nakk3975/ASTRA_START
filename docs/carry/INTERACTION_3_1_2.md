# 3.1.2 — 이동·상호작용 정합성

2026-11-17 KST. 게임 버전 3.1.2, 저장 규칙 quarry-3.1.0 유지.

## 동작 변경

- 이동 직후 E 대상과 설치 미리보기, 기계 안내, 카메라 재중앙이 화면에 보이는 캐릭터 위치와 방향을 사용한다. 서버는 클라이언트 좌표를 신뢰하지 않고 입력 구간을 재현한다.
- 행동 시점의 이동 번호를 봉인하고 해당 구간까지 서버에서 처리한 후 행동한다. 패킷 분할·시간 예산 때문에 이동이 남았다면 명령을 소비하거나 자금을 차감하지 않고 동일 ID로 재시도한다.
- 키업 뒤 늦게 도착한 이동은 마지막 이동 방향을 유지한다. 재접속 때 이전 세대의 경계만 제거하고 명령 중복 처리를 방지한다.
- 걷기 애니메이션은 실제 표시 위치 변화로 판정한다.
- 합쳐지는 미전송 이동 구간은 시작 위치에서 전체 시간으로 다시 계산한다. 렌더 프레임별 적분과 서버 구간 적분의 차이 때문에 벽 모서리에서 남던 0.6~1.1cm 오차를 수정했다.
- package.json의 3.1.2를 로비·메뉴 및 게시 서버 health 응답에서 공통으로 사용한다.

## 검증

- `npm run check`: 설계 검사, 107개 테스트, TypeScript, Vite 빌드 통과.
- `tests/interaction-timeline.test.ts`: 6개 회귀 시험. 이동 직후 행동, 40개 패킷 분할, 시간 예산, 무효 경계, 진행 중 요청, 재접속/늦은 응답을 검증한다.
- `tests/movement-collision.test.ts`: 60·144·240·360Hz 각 3가지(광맥 모서리, 경사로 상행, 경사로 하행), 300ms 응답 지연. 바닥 범위·높이, 정지 후 변위, 최종 서버 일치와 빈 대기열 확인. 오차 허용치 1e-7.
- 기존 고주사율·지연·역순 응답 검증을 함께 실행했다.
- `npm run test:carry:network`: 실제 6개 Colyseus WebSocket과 PostgreSQL. 7번째 사용자 거부, 물건 경합, 이동/키업/중복 입력, 행동 경계, 연결 해제 회수, 프로세스 재시작 저장 복구 통과.
- 복구 커밋 044072d8c304b266e9c3b0fa9dbf7cd242a74be6의 GitHub Actions 전체 성공 확인. 이 이후 릴리스 커밋의 CI 결과는 해당 커밋에서 확인한다.

## 검증 범위와 배포

원격 QA 브라우저는 WebGL2를 제공하지 않는다. CPU 계산·서버 검증이 실제 GPU FPS, 3D 외관, 사람이 느끼는 이동 감각이나 사람이 협동한 6인 플레이를 보증하지 않는다. 기존 오프라인 렌더는 게임 실행 캡처가 아니다.

기존 소유자 전용 Site와 GitHub draft PR #1을 갱신한다. 기존 저장 데이터·밸런스·모델·공개 범위는 유지하며 main은 병합하지 않는다. 실행 환경 중단은 복구되어 릴리스 패키징을 재개했다. 게시 여부는 Site 최신 버전과 화면/health의 3.1.2 표시를 기준으로 확인한다.
