# 이동 직후 상호작용 — 3.1.2

2026-11-17 KST. 저장 규칙은 `quarry-3.1.0` 유지.

## 문제와 수정

화면의 캐릭터는 로컬 예측으로 즉시 이동하지만 E 대상, HUD 안내, 가까운 기계 패널, 설비 미리보기는 이전 서버 좌표로 계산했다. 지연 중에는 광맥에 도착해 보이는데 채굴 대상이 없거나, 돌아선 직후 설치 미리보기가 이전 방향에 남을 수 있었다.

- 같은 표시 위치와 마지막 입력 방향으로 E 대상·안내·미리보기·C 재중앙을 계산한다. 서버는 입력 구간을 재현해 위치·거리·충돌·비용을 계속 판정한다.
- 행동 순간의 이동 순번을 봉인한다. 행동 이후의 이동은 해당 행동 ACK 이후 전송한다. 이미 전송한 구간의 시간이나 방향은 바꾸지 않는다.
- 이동이 여러 패킷으로 나뉘거나 서버 시간 예산으로 지연되면, 마지막 구간을 적용할 때까지 행동의 소비/영수증 생성을 보류한다. 같은 명령 ID로 재시도해 중복 지급을 막는다.
- 일반 HTTP 동기화가 진행 중이어도 행동을 우선 전송한다. 재접속 세대가 바뀌면 옛 이동 대기 조건만 제거하며 명령 ID는 보존한다.
- 정지 패킷이 먼저 도착해도 마지막으로 적용한 이동 방향을 기억한다. 걷기 애니메이션은 실제 표시 변위로 결정한다.

## 검증과 한계

| 항목 | 결과 |
|---|---|
| 전체 단위시험 | 연결 중단 전 103개 통과 |
| 신규 회귀시험 | 도착 즉시 채굴, 분할 패킷, 시간 예산, 행동 시점 봉인, 우선 전송, 재접속·늦은 응답 6개 통과 |
| TypeScript / Vite | 연결 중단 전 통과 |
| 설계 검산 | 통과; 기존 경제 수치 유지 |
| 실제 WebSocket 6클라이언트 + PostgreSQL | 같은 아이템 경합, 정지, 이동 완료 후 행동, 연결 종료 회수, DB 재시작 통과 |
| 원격 브라우저 | 로비·새 작업장 접속 확인; WebGL2 제공 안 됨 |
| 실제 GPU 외관·FPS·사람의 조작감 | 미검증 |
| 이 변경의 Sites 배포 | 미완료: 실행 환경 연결 끊김 |

실행 환경이 배포 준비 중 연결 해제되어 검증한 수정 패치와 회귀시험을 기존 GitHub 베이스에 재적용해 저장했다. 포매팅 차이는 있을 수 있으며, 복구 커밋 자체의 실행·타입검사·빌드는 환경 복구 후 다시 확인해야 한다. Sites는 종전 3.1.1/v8 상태다. GitHub 소스 저장을 Sites 배포 완료로 혼동하지 않는다.

벽 모서리 주변의 분할 적분 탐색에서 약 0.6~1.1cm의 표시/권위 잔여 오차가 관측됐다. 모든 지형에서의 픽셀 단위 일치나 GPU 조작감 개선을 완료했다고 주장하지 않는다.

모델·광맥·레시피·설비 가격·자금·저장 데이터는 변경하지 않았다. 신규 모델 생성 비용은 없다.

```sh
npm run check
npm run test:carry:network
```
