# 3.3.0 — 설치 보상과 작업 진행 표시

## 철판 만드는 순서

1. 철광석을 채굴해 작업대 금색 입력 받침대에 E로 넣는다.
2. 청록 출력 받침대에서 철 주괴를 받는다.
3. 작업대 근처의 **② 철판 만들기**를 선택한다. 가공 중이거나 입력 재료가 남았다면 먼저 완료/회수한다.
4. 주괴 1개를 금색 받침대에 넣고 철판 1개를 받는다.
5. 발사대의 철판 소켓에 설치하면 기본 1코인을 받는다.

초반 안내 패널이 작업대 메뉴와 동일 위치를 덮던 문제를 수정했다. 작업대 근처에서는 제작 메뉴가 우선 표시된다. 전체 제작 목록, 재료→결과, 실제 강화 속도가 반영된 소요 시간, 입출력 위치 안내를 함께 제공한다.

## 설치 중심 경제

판매소의 모델과 상호작용을 제거했다. 이전 클라이언트의 SELL 요청은 물건/자금을 변경하지 않고 거절한다. 가공은 XP만, 로켓 설치는 코인만 지급한다. 설비 설치/회수 반복에는 보상이 없다. 별도의 단계 완성 코인 보너스도 제거했다.

| 설치 부품 | 기본 보상 |
|---|---:|
| 철 주괴·철판·기어 | 1 |
| 구리선 | 2 |
| 내열재 | 3 |
| 회로·선체 패널 | 4 |
| 연료 | 5 |
| 엔진 | 6 |
| 항법 | 7 |

보상은 실제 로켓 소켓 설치가 성공할 때만 지급한다. 각 소켓의 기존 요구 재료는 유지한다. 부품 품질 등급만큼 코인을 더하며 혼합 품질은 기존처럼 가장 낮은 입력 재료를 따른다. 중복 명령/경합은 기존 명령 영수증과 저장 CAS로 한 번만 반영한다.

판매를 없앤 상태에서 유한한 설치 보상을 전부 선택 구매에 사용해도 필수 진행이 막히지 않도록 필수 해금은 XP 조건으로 무료 제공한다. 구리12 → 규석24 → 석탄60 XP, 순차 해금이다. 기본 작업대도 24 XP에서 회로·선체·연료, 50 XP에서 엔진·항법 제작법을 사용할 수 있다. 광맥 조건도 함께 만족해야 한다. 기계 강화는 속도/출력 용량에 적용되며 추가 작업대 2코인, 첫 강화 3코인 등 선택 구매 가격도 조정했다. 이전 저장의 잔액/장비/아이템/광맥 상태는 초기화하지 않는다.

## 화면과 소리

- 정사영 카메라 거리 기본32→22, 범위12~48. 같은 해상도에서 캐릭터/설비 약1.45배 확대. 휠 위로 확대, 아래로 축소, +/-와 기본값 버튼, 부드러운 전환. Ctrl+휠은 브라우저 조작을 유지하고 모달 위에서는 월드 줌을 막는다.
- 기본 글자와 반응형 UI 배율을 확대했다. 방 코드 패널 줄바꿈으로 확인된 넘침을 수정했다.
- 작업자/기계/자동 설비 위 화면 좌표 게이지: 진행률·남은초, 완료, 출력 공간 대기. 줌해도 글자/막대 크기를 화면 픽셀 기준으로 유지한다. 작업대 패널에도 동일 진행 정보를 제공한다. 클라이언트 예측만으로 완료했다고 표시하지 않는다.
- 공유 AudioContext 하나로 발걸음·채굴·가공·집기·투입·내려놓기·던지기·완료·설치·보상·해금·핑·발사·오류·선택음을 합성한다. 사용자 입력 후 활성화하며 음량과 음소거를 제공한다. 반복 음향 간격 제한, 이전 이벤트와 재전송 응답의 중복 재생 방지, 탭 비노출 음향 차단, 종료 시 정리.

## 검증과 한계

설계 검사, 126개 테스트, TypeScript/Vite 빌드 통과. 신규 회귀 시험은 정확한 1코인/중복 지급 방지/상위 부품/판매 차단/필수 무자금 진행/3.2 저장 마이그레이션/진행 게이지 계산/휠 범위/음향 이벤트 구분과 중복 억제를 다룬다. HTTP Worker와 실제 SQLite 저장 시험도 포함한다. 실제6개 WebSocket/PostgreSQL 시험의 입장 제한·경합·이동·중복 명령·DB 재시작 복구도 통과했다.

1·2·4·6인 목표량에 대해 단일 이동 봇이 0원·작업대1대에서 아이템/자금/위치 주입 없이 발사까지 완주했다. 판매0회, 추가 연습0회, 작업대 구매·설치·회수·재설치 포함. 이는 사람의 협동 플레이 시간 측정이 아니다. 증거: `evidence/progression-3.3-campaign-{1,2,4,6}.json`.

브라우저에서 v3.3.0, 새 작업장/재접속, 확대 버튼100→110%, 음량45%/거리20 설정, 1363×936에서 패널 넘침 수정 확인. 검증 브라우저의 WebGL2 미지원으로 실제 GPU/FPS/3D 휠 줌/월드 게이지 외관/사람의 협동 조작감은 미검증이다. 음향 코드는 경로와 이벤트를 검증했으며 청음 품질 검증은 하지 않았다.
