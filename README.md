# 고철에서 우주까지 · From Scrap to Space

광맥에서 쉽게 채굴하고, 직접 운반·가공·설치하며 자동화를 확장하는 1~6인 협동 웹게임입니다. 최신 규칙은 **mining-2.1.0**입니다.

[게임 열기](https://scrap-to-orbit-model-review.dsfs3975.chatgpt.site) · [구현·검증 보고서](docs/carry/IMPLEMENTATION.md) · [이어서 작업하기](docs/RESUME.md)

## 이번 버전

- 광맥에서 E 한 번으로 0.6초 채굴. 바닥에 자원이 자동 생성되지 않습니다.
- 주괴·철판·회로·엔진 등 여러 단계 가공. 깊게 가공할수록 누적 코인과 XP 증가.
- 팀 업그레이드로 운반량 **1→2→3개**, 컨베이어, 채굴기, 크레인, 자동 설치기 해금.
- 채굴→기계 투입→가공→출력 수거→발사대 운반→설치 자동화. 막힌 출력은 대기하며 물건을 삭제하지 않습니다.
- 26종 모델 카탈로그. 작업자는 안전모와 작업복을 입은 새 사람 모델로 교체했습니다. 기본 골격과 다섯 동작을 연결했습니다.
- 서버가 이동·소유권·제조·비용을 결정하고 저장 후 응답합니다. 1~6명 기준 목표량은 방 생성 시 고정됩니다.

**검증 상태:** 설계 검사, 78개 테스트, TypeScript/빌드, 실제 6개 WebSocket 클라이언트와 PostgreSQL 재시작 시험 통과. 원격 QA 브라우저의 WebGL이 비활성화되어 실제 3D 외관·애니메이션·FPS·사람의 정상 시간 완주는 아직 검증하지 못했습니다. 현재 개발 빌드이며 출시 완료 판정은 아닙니다.

## 실행

Node **24.22.1 이상, 25 미만**:

```bash
npm ci
npm run dev
```

http://localhost:2567 에서 실행합니다. 개발 모드에서 DATABASE_URL이 없으면 `.local/postgres`에 실제 PostgreSQL을 자동 준비합니다. Windows에서 자동 DB 실행이 지원되지 않는 경우 기존 PostgreSQL 주소를 `.env`의 DATABASE_URL에 지정하세요. 운영 환경 변수와 백업은 [운영 문서](docs/OPERATIONS.md)를 참고하세요.

| 경로 | 용도 |
|---|---|
| `/` | 새 채굴·운반·자동화 게임 |
| `/asset-review` | 26종 모델과 동작 검수; WebGL 불가 시 원본 미리보기 |
| `/legacy` | 기존 v1 규칙과 저장; Node/PostgreSQL 서버에서 실행 |

## 함께 플레이

이름과 난이도 기준 인원을 선택하고 작업장을 만듭니다. 상단의 **8자리 방 코드**를 같은 서버에 접속한 친구에게 전달합니다. 최대 6명이며, 같은 브라우저 프로필의 이어하기는 기존 세션의 제어권을 교체합니다.

게시된 링크는 기존 **소유자 전용 공개 범위**를 유지합니다. 친구가 접근하려면 사이트 공유 권한을 별도로 설정해야 합니다. 로컬 주소는 다른 PC에서 바로 열리지 않습니다.

Node 서버는 Colyseus WebSocket + PostgreSQL, 게시 사이트는 HTTP 상태 동기화 + D1을 사용합니다. 두 환경의 저장은 별개입니다. 기존 v1 저장과 새 규칙 저장도 분리되어 있습니다.

| 조작 | 기능 |
|---|---|
| WASD / 방향키 | 화면 기준 이동 |
| E | 채굴, 들기, 기계 투입, 소켓 설치 |
| Q | 여러 운반물 중 사용할 물건 변경 |
| Space / F | 내려놓기 / 짧게 던지기 |
| 1~6 / R | 설비 선택 / 회전; 코너는 양방향 8상태 |
| C / G | 카메라 재중앙 / 팀 핑 |
| Esc | 배치 취소, 창 닫기, 메뉴 |
| 팀 자금 버튼 | 운반량·자동화·가공 속도 업그레이드 |

해금 후에도 설비 상자를 작업대에서 제작하고 직접 운반해 설치해야 합니다. 가공기 가까이에서 제조법, 필요 재료, 보상을 확인할 수 있습니다. 현재 새 게임은 데스크톱 키보드 조작 기준입니다.

```bash
npm run check
npm run test:carry:network
npm run test:carry:campaign
npm run build:sites
```

이전 게임의 실행·기능 문서는 [이전 README](docs/carry/PRIOR_README.md)에 보존했습니다. 이전 경제 JSON과 시험을 새 규칙의 완료 증거로 혼동하지 마세요.
