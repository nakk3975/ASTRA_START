# 고철에서 우주까지 · From Scrap to Space

광맥에서 쉽게 채굴하고, 직접 운반·가공·설치하며 자동화를 확장하는 1~6인 협동 웹게임입니다. 최신 규칙은 **quarry-3.4.0**입니다.

[게임 열기](https://scrap-to-orbit-model-review.dsfs3975.chatgpt.site) · [이동·채굴장 개선](docs/carry/QUARRY_3_1.md) · [성장·밸런스](docs/carry/GROWTH_3_0.md) · [이어서 작업하기](docs/RESUME.md)

## 이번 버전

- **3.4.0:** 철판 설치·3D 재시작의 객체 정리 예외 수정, 로켓 모델 재사용, 재료에 따른 자동 가공, 운반 자세·보폭 개선, 통신 오류 반복 방지. [변경·검증 기록](docs/carry/RECOVERY_3_4.md).

- **3.3.0:** 판매소 제거·부품 설치 보상, 무료 필수 해금, 철판 제작 바로가기, 채굴/가공 게이지, 기본 확대·휠 줌, 행동별 효과음. [변경·검증 기록](docs/carry/EXPERIENCE_3_3.md).
- **3.2.0:** 작업대 설치 후 이름표까지 가림 검사를 하면서 발생하던 화면 정지 예외를 수정했습니다. 새 작업장은 0코인·낡은 작업대 1대·철광석만으로 시작하며 구리 → 규석 → 석탄을 순서대로 해금합니다. [변경·검증 기록](docs/carry/PROGRESSION_3_2.md).


- **3.1.2:** 이동 직후 E/설치의 대상과 미리보기를 화면 위치에 맞췄습니다. 행동 시점까지의 이동을 서버가 적용한 뒤 행동을 한 번 처리합니다. 키를 놓은 직후의 방향과 실제 이동에 따른 걷기 동작도 보정했습니다. 벽 모서리·경사로에서 렌더 주사율에 따라 남던 위치 오차를 수정하고 로비·메뉴에 버전을 표시합니다. [변경·검증 기록](docs/carry/INTERACTION_3_1_2.md).

- **3.1.1:** 144/240/360Hz에서 통신 지연 시 이동이 누락되던 대기열을 수정했습니다. 초반 설비 6종을 모루·가마·수동 프레스 등 서로 다른 외형으로 구분했습니다. [변경·검증 기록](docs/carry/REFRESH_3_1_1.md).
- 키를 놓은 뒤 재이동하는 문제를 입력 구간 번호·서버 확인·미확인 구간 재현으로 수정했습니다. HTTP 요청이 진행 중이어도 키업을 즉시 전송합니다.
- 철광석·구리광석·규석·석탄 채굴 모델 4종과 원재료 외형을 교체하고, 야외 흙길·목재 울타리로 맵을 바꿨습니다.

- **0코인 + 최하위 낡은 작업대 1대 + 철광석**으로 시작합니다. 필수 광맥과 제작법은 XP 조건으로 무료 해금하고, 로켓 설치 보상으로 추가 설비·강화를 구매합니다. 추가 작업대는 2코인입니다.
- 광맥에서 E 한 번으로 0.8초 채굴. 가공은 XP, 로켓 설치는 코인을 줍니다. 철판 1, 선체 4, 연료 5, 엔진 6, 항법 7코인입니다. 단계를 더 거친 부품은 가치가 높아집니다.
- 운반량 **1→2→…→8개**, 이동속도 5단계(+30% 상한), 무거운 짐 운반·채굴 도구·레일 모터·가공 조율을 따로 연구합니다.
- 설비별 **낡은→개량→산업→정밀** 4등급, 네 광맥 각각 5등급. 비용·경험치·선행 조건을 충족해야 강화됩니다.
- 컨베이어→자동 채굴·크레인→자동 설치를 해금합니다. 상자를 구매하거나 제작해 직접 놓아야 가동됩니다. 설비를 재포장해 옮겨도 등급을 보존합니다.
- 사람형 캐릭터 **4종**을 플레이어마다 선택합니다. 능력은 같고 외형만 다릅니다. 실제 모델 카탈로그는 29종, LOD 파일은 58개입니다.
- 이동 입력은 화면에 즉시 반영합니다. 다른 플레이어는 보간하고 정사영 카메라는 표시 위치를 따라갑니다. 정지 후 카메라의 지연 이동과 운반물의 뒤늦은 방향 전환을 수정했습니다.
- 기존 저장은 자금·설비·물건을 보존해 이전합니다. 새로운 0코인·철광석 시작 조건을 적용하려면 **새 협동 작업장**을 만드세요.

**검증:** 설계 검사, 135개 테스트, TypeScript/빌드, 실제 6개 WS 클라이언트와 PostgreSQL 재시작 통과. 3.4 재료 자동 가공·판매 없는 시작 조건에서 1·2·4·6인 목표량 이동 봇이 광맥 해금·추가 구매·설치·회수·재설치를 거쳐 발사까지 완주했습니다. 원격 QA 브라우저에서는 WebGL2가 없어 실제 3D 외관·관절·FPS·사람의 플레이 감각은 미검증입니다. UI 구매/차감과 60~360Hz 지연 상황의 이동 계산은 별도 검증했습니다.

## 실행

Node **24.22.1 이상, 25 미만**:

```bash
npm ci
npm run dev
```

http://localhost:2567 에서 실행합니다. 개발 모드에서 DATABASE_URL이 없으면 `.local/postgres`에 실제 PostgreSQL을 자동 준비합니다. Windows에서 자동 DB 실행이 지원되지 않는 경우 기존 PostgreSQL 주소를 `.env`의 DATABASE_URL에 지정하세요. 운영 환경 변수와 백업은 [운영 문서](docs/OPERATIONS.md)를 참고하세요.

| 경로 | 용도 |
|---|---|
| `/` | 새 채굴·운반·자동화 게임 |
| `/asset-review` | 29종 모델과 동작 검수; WebGL 불가 시 원본 미리보기 |
| `/legacy` | 기존 v1 규칙과 저장; Node/PostgreSQL 서버에서 실행 |

## 함께 플레이

이름과 난이도 기준 인원을 선택하고 작업장을 만듭니다. 상단의 **8자리 방 코드**를 같은 서버에 접속한 친구에게 전달합니다. 최대 6명이며, 같은 브라우저 프로필의 이어하기는 기존 세션의 제어권을 교체합니다.

게시된 링크는 기존 **소유자 전용 공개 범위**를 유지합니다. 친구가 접근하려면 사이트 공유 권한을 별도로 설정해야 합니다. 로컬 주소는 다른 PC에서 바로 열리지 않습니다.

Node 서버는 Colyseus WebSocket + PostgreSQL, 게시 사이트는 HTTP 상태 동기화 + D1을 사용합니다. 두 환경의 저장은 별개입니다. 기존 v1 저장과 새 규칙 저장도 분리되어 있습니다.

| 조작 | 기능 |
|---|---|
| WASD / 방향키 | 화면 기준 이동 |
| E | 채굴, 들기, 기계 투입, 소켓 설치 |
| Q | 여러 운반물 중 사용할 물건 변경 |
| Space / F | 내려놓기 / 짧게 던지기 |
| 1~6 / R | 설비 선택 / 회전; 코너는 양방향 8상태 |
| C / G | 카메라 재중앙 / 팀 핑 |
| Esc | 배치 취소, 창 닫기, 메뉴 |
| 팀 자금 / 설비 구매 | 연구·설비 강화·광맥 개발 / 상자 구매 |

해금 후에도 설비 상자를 구매하거나 제작하고 직접 운반해 설치해야 합니다. E로 배치 모드에 들어가 가까운 바닥을 클릭하고 R로 회전합니다. 가공기 가까이에서 제조법, 필요 재료, 보상을 확인할 수 있습니다. 현재 새 게임은 데스크톱 키보드 조작 기준입니다.

```bash
npm run check
npm run test:carry:network
npm run test:carry:campaign
npm run build:sites
```

이전 게임의 실행·기능 문서는 [이전 README](docs/carry/PRIOR_README.md)에 보존했습니다. 이전 경제 JSON과 시험을 새 규칙의 완료 증거로 혼동하지 마세요.
